# Agenda de Contactos

Programa en Python que resuelve un problema sencillo de la vida real:
registrar contactos con su **nombre** y **número telefónico** usando un
**diccionario** como estructura de datos.

## ESTUDIANTE 

ANTHONNY DANIEL MOSQUERA MEDINA 

## Estructura de datos utilizada

- **Diccionario**: la clave es el nombre del contacto y el valor es su
  número telefónico. Permite acceso rápido por nombre.

## Funcionalidades

1. **Agregar contacto**: inserta un nuevo contacto (nombre y teléfono).
2. **Buscar contacto**: busca por nombre y muestra su número.
3. **Eliminar contacto**: borra un contacto existente.
4. **Listar contactos**: muestra en pantalla toda la información guardada.
5. **Salir**: termina el programa.

## Cómo ejecutar

Requisito: tener Python 

```bash
python contactos.py
