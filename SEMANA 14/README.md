Programa en Python que calcula el área de un rectángulo utilizando una función con parámetros y retorno de valor.

## Descripción
Este programa solicita al usuario la base y la altura de un rectángulo, calcula su área mediante una función y muestra el resultado en pantalla.

## Cómo funciona
1. Se define la funcion `calcular_area_rectangulo(base, altura):`
2. Recibe los parámetros 
     area = base * altura
3. Se ingresan los valores a calcular`base = float(input("Ingrese la base: ")) 
altura = float(input("Ingrese la altura: ")) `
4. Realiza el cálculo `calcular_area_rectangulo (base, altura)`
5. Se obtiene el resultado
